# 01-recon

Fase de reconocimiento: footprinting, OSINT, descubrimiento de objetivos y superficie de ataque.

## Qué va aquí
- Scripts de footprinting y OSINT (`whois`, `dns`, `subdomain`, email harvesting...)
- Descubrimiento de hosts en la red (pingsweep, ARP, escaneo ligero)
- Recopilación pasiva y activa antes de enumerar servicios

## Subcarpetas por plataforma
- `windows/` → scripts PowerShell/cmd
- `linux/` → scripts bash/python
- `web/` → inteligencia sobre aplicaciones web

Linux first: crea subcarpetas solo cuando haya contenido para cada una.
