# 06-persistence

Métodos para mantener acceso a los objetivos tras reinicios o desconexiones: persistencia y comunicaciones C2.

## Qué va aquí
- Técnicas de persistencia Windows (tareas programadas, RunKey, servicios, WMI...) y Linux (`systemd`, cron, rc.local...)
- Revershells persistentes / agentes ligeros
- Configuración de C2 (listeners, staging)

## Subcarpetas por plataforma
- `windows/`, `linux/`
