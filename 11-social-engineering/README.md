# 11-social-engineering

Ingeniería social y phishing: clonado de sitios, campañas de correo, payloads por adjunto, generadores de QR/USB.

## Qué va aquí
- Cheatsheets de frameworks (SET, gophish, Evilginx...)
- Clonadores de sitios y captura de credenciales
- Plantillas de phishing (HTML de páginas de login)
- Masas de correo (SMTP, SMTP2Go, Sendmail)

## Subcarpetas sugeridas
- `linux/` para herramientas tipo SET (Kali/Parrot)
- `templates/` para páginas HTML clonadas o falsificadas
